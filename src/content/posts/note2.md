# C++面向对象之多态

多态的意思是：同一个函数调用，根据对象的实际类型，执行不同版本的函数。

运行时多态通常需要三个条件：

- 有继承关系
- 基类中把某个函数声明为`virtual`（虚函数）
- 通过**基类指针或引用**调用这个函数

> 这看着确实抽象，下面结合实例来看

```c++
class Animal {
public:
    virtual void speak() { //声明这是一个虚函数
        std::cout << "动物叫\n";
    }
};

class Dog : public Animal {
public:
    void speak() override { 
        //override意为告诉编译器，这是重写的虚函数，而非普通函数，写错了编译器会报错
        std::cout << "汪汪\n";
    }
};

class Cat : public Animal {
public:
    void speak() final { 
        //final意为告诉编译器，这里是重写的终点，后续所有继承cat的子类都不能再重写speak()
        std::cout << "喵喵\n";
    }
};

int main() {
    Dog d;
    Cat c;

    Animal* p1 = &d;
    Animal* p2 = &c;//p1、p2是类型为Animal的指针，是Dog和Cat的基类，也就是基类指针

    p1->speak();    // 输出：汪汪
    p2->speak();    // 输出：喵喵
}
```

可以看到，基类中用virtual void speak()定义了一个虚函数，virtual就是定义虚函数的关键字。

这里有一个新概念：虚函数，下面详细讲一下虚函数，了解虚函数后就容易理解多态了。

## 虚函数

虚函数就是在类里用`virtual`关键字声明的成员函数。多态主要就是通过虚函数实现的。

虚函数的作用是：

- 允许子类重新定义这个函数；
- 当**通过基类指针或引用调用**时，程序会在运行时根据对象的真实类别，决定调用哪个版本的函数。

### 调用类型/指针与引用

```C++
Dog d;

//基类指针调用
Animal* a = &d;
a->speak(); //指针调用要使用“->”

//引用调用
Animal& b = d;//必须绑定一个对象
b.speak(); //引用调用使用“.”
```

通过虚函数，就可以通过顶层基类统一管理与调用不同子类的同名函数，并且发挥不同的效果

> 这里的两个`&`具有不同含义，当`&`放在变量前面时，意思是取址；当`&`跟在类型后面时，表示引用
>
> ```C++
> int a = 5;
> int* p = &a; //得到a的地址，赋给指针p
>
> int& r = a; //r是a的引用，绑定后不能再更改
> ```
>
> r作为a的别名，在大多数情况与a等价，但还有以下区别
>
> ```C++
> int& &rr = r;          // 错误：不能定义引用的引用
> int& arr[3] = {a,a,a}; // 错误：不能定义引用的数组
> int&* pr = &r;         // 错误：不能定义指向引用的指针
> int& rb;               // 错误：引用必须初始化
> int* p = &a;           // 合法，可以定义指向 a 的指针
> ```

## override

阅读代码可以发现，通过重写（override）基类虚函数，同一个函数能根据对象的不同自动调用合适的方法，好处是可以用统一的接口，处理不同的具体类型，而且新增类型时不用改调用代码。

里面有两个关键字，override和final

override会让编译器帮你检查这个函数是不是真的重写了基类的虚函数。比如上面dog类的代码如果这样写

```C++
class Dog : public Animal {
public:
    void speak(int x) override { //报错：使用override声明的成员函数不能重载其基类成员
        std::cout << "汪汪\n";
    }
};
```

如果去掉 override，写错的函数会把基类的函数隐藏，多态就消失了，并且难以排查。

> 如果你能确保每次写的都一样，那么不写override多态也能正常生效。多写一个就当上保险了，也能增加代码可读性。

注意区分`重载(overload)`和`重写(override)`。重载是同一作用域，函数名相同，参数不同，这时编译器会根据入参判断调用具体哪个函数

```C++
void print(int x) {
    std::cout << "整数：" << x << "\n";
}
void print(double x) {
    std::cout << "小数：" << x << "\n";
}
void print(const std::string& s) {
    std::cout << "字符串：" << s << "\n";
}
```

## final

这个比较好理解，意思是虚函数的重写到此为止，继承我的子类都不能再重写这个函数。颇有一种过河拆桥的意味。

```C++
class Kitty : public Cat{
public:
    void speak() override{ //错误，其基类已将speak声明为final，子类不允许重写
        std::cout << "Hello Kitty";
    }    
};
```

> final也可以用来修饰类，被final修饰后该类就无法被继承

## 纯虚函数

前面的例子中，Animal::speak()还有函数体

```C++
virtual void speak(){
    std::cout << "动物叫\n";
};
```

这种叫普通虚函数，基类给了默认实现。

纯虚函数是另一种写法，直接在函数后面写`=0`，并且通常不写函数体

```C++
class Animal{
    public:
    virtual void speak() = 0; //纯虚函数
};
```

`=0`表示:这个函数只定义接口，不提供默认实现，子类必须自己实现这个功能。

## 抽象类

只要一个类里面有纯虚函数没有实现，那么这个类就被称做抽象类。

### 特点

抽象类不能创建对象

```C++
Animal a; //错误！抽象类不能创建对象
```

但可以定义基类指针或者引用：

```C++
Animal* p;
Animal& r = d;//d是派生类对象
```

抽象类的子类必须实现纯虚函数，否则这个子类也是抽象类，无法创建对象；

### 作用

作为一个接口规范，规定子类必须实现的功能，但具体实现由子类决定。

> 抽象类里可以有普通成员变量，成员函数，已经实现好的虚函数。但只要存在没有实现的纯虚函数，这个类就是抽象类

## 析构函数

析构函数是对象**销毁**时**自动调用**的函数，用来做清理工作

### 语法

```C++
class Dog{
    public:
    ~Dog(){
        std::cout << "Dog Destroyed!\n";
    }
};
```

### 特点

- 名字是`~`加类名，
- 没有参数
- 没有返回类型
- 不能重载，一个类只能有一个析构函数
- 对象生命周期结束时自动调用

### 何时调用

1.离开作用域时

```C++
int main(){
    Dog d;         //创建对象
}                  //离开作用域，自动调用~Dog()
```

输出:

```text
Dog Destroyed!
```

2.动态分配时

```C++
Dog* p = new Dog; //创建对象
delete p;		 //手动销毁，自动调用~Dog()
```

`new`创建对象，`delete`销毁对象并调用析构函数

如果不写`delete`，析构函数就不会被调用，可能造成资源泄露

### 作用

一般用来释放对象占用的资源

### 和构造函数的关系

- 构造函数：对象创建时调用，负责初始化。
- 析构函数：对象销毁时调用，负责清理

顺序：

- 创建时：先基类构造，再派生构造
- 销毁时：先子类析构，后基类析构

> 其实是个很直观的过程，创建时可以想象成一个链式结构从近端延伸到远端，那么销毁时应该反过来，先从远端到近端

### 虚析构函数

虚析构函数和虚函数是一个思想，能理解虚函数就能理解虚析构函数了。具体来说虚析构函数会通过基类指针`delete`指向子类对象，能动态调用子类的析构函数。

```C++
class Animal { 
public : 
    virtual ~ Animal () { 
        std::cout << "~Animal\n" ; 
    } 
};
int main(){
    Animal* p = &d;
    p->speak();   // 手动调用，触发多态

    Animal* d = new Dog;
    delete d;     // 由 delete 触发，自动根据真实类型调用析构函数
}

```

delete之后的自动调用析构函数交给编译器自动执行就行了。

## 虚函数表

虚函数表是多态的核心机制。

如果一个类包含虚函数，编译器需要在运行时支持动态绑定

> 即编译期无法确定调用哪个函数，要等到运行时根据对象实际类型确定

为了实现这一点，引入了虚函数表和虚表指针。

### 虚函数表定义

- **如果一个类有虚函数，编译器会为这个类生成一张虚函数表，简称`vtable`，本质上是一个数组，存储着该类所有虚函数的函数指针。**
- 虚表中存储了该类所有虚函数的地址，如果派生类重写了基类的虚函数，则派生类中的虚表会替换为自身重写的函数地址；未重写的虚函数地址则继承自基类

### 特点

- 每个含虚函数的类都会有一张虚表。
- 继承关系：
- <br />
  - 派生类会继承基类的虚表，但会根据重写情况替换虚表对应的条目
  - 如果派生类新增了虚函数，这些函数地址会被添加到虚表末尾
- 虚表在编译期确定，但调用时选择哪个表由对象的类型决定
- 虚表通常存储在只读段中，不随对象复制而重复

### 虚表指针定义

- 每个包含虚函数或继承了虚函数的类的**对象**，都会包含一个指向虚表的成员指针，这个指针就是虚表指针
- 虚表指针通常位于对象内存布局的开头，作为对象的隐藏成员存在

### 行为

- 当对象构建时，编译器在构造函数里自动初始化虚表指针，让它指向对应类的虚表，因此，类的构造函数不能是虚函数。
- 如果是派生类对象，则在执行派生类构造函数时会更新虚表指针，使其指向派生类的虚函数表。
- 调用虚函数时，编译器做的是：
- <br />
  - 1.通过对象找到虚表指针
  - 2.通过虚表指针找到虚表
  - 3.从虚表中取出对应函数指针
  - 4.执行函数

### 重要细节

1.多继承

- 如果一个类同时继承多个具有虚函数的类，编译器会为对象设置多个虚表指针，对应不同基类的虚表指针。

2.虚继承

- 在多重继承中可能会出现菱形继承问题，导致派生类调用成员时产生二义性，使用虚继承可以解决这个问题，但最好的方式还是尽量不要使用多继承。
- 在虚继承的情况下，虚表会更复杂，还会存储基类子对象的偏移量。
